# 实现范围与后续规划

## 已实现

- New API 项目连接卡片、分组/渠道元数据同步、正式 2FA 密钥导入。
- 服务端加密存储、项目间隔计划、手动批量巡检、批次记录与重启中断恢复。

- Go API、React + TypeScript 工作台和同源开发代理。
- 环境变量共享密钥登录、会话过期与注销。
- 模型 Provider / 检测 Evaluator 双接口、显式注册、动态能力列表。
- OpenAI 兼容模型发现，全部/指定模型扫描，指定模型不依赖发现接口。
- 内置三项 smoke 检查、异步任务、内存快照、结果与调用错误分开呈现。
- Fingerpoint Detector Go SDK、懒加载参考数据与独立指纹检测页面。
- 本地模拟服务的行为测试。

## 下一步候选（尚未实施）

1. 加入持久化任务、结果与题库版本。先明确旧库迁移、新库初始化、任务恢复路径；不提前创建无用迁移文件。
2. 按真实调用量增加全局并发队列、速率限制、取消和成本预算。
3. 扩展原生厂商协议、工具调用、上下文、代码、视觉等能力；针对每种能力声明适用模型。
4. 需要多人隔离或公网部署时，补账户归属、权限、出站网络策略、限流和审计。

不默认接入某个评测框架，不预设统一智力分数。标准化题库、LLM judge、报告导出和历史回归比较需要另行确定具体契约。

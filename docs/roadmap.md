# 实现范围与后续规划

## 已实现

- Go API、React + TypeScript 工作台和同源开发代理。
- 环境变量共享密钥登录、会话过期与注销。
- 模型 Provider / 检测 Evaluator 双接口、显式注册、动态能力列表。
- OpenAI 兼容模型发现，全部/指定模型扫描，指定模型不依赖发现接口。
- 内置三项 smoke 检查、异步任务、内存快照、结果与调用错误分开呈现。
- 本地模拟服务的行为测试。

## 下一步候选（尚未实施）

1. 选定第一个真实检测 SDK，验证其模型调用协议、题库许可、结果定义、依赖大小和取消能力；以它为依据设计独立扩展运行方式。
2. 加入持久化任务、结果与题库版本。先明确旧库迁移、新库初始化、任务恢复路径；不提前创建无用迁移文件。
3. 按真实调用量增加服务端并发队列、速率限制、取消、成本预算和定时巡检。
4. 扩展原生厂商协议、工具调用、上下文、代码、视觉等能力；针对每种能力声明适用模型。
5. 需要多人隔离或公网部署时，补账户归属、权限、出站网络策略、限流和审计。

不默认接入某个评测框架，不预设统一智力分数。标准化题库、LLM judge、报告导出和历史回归比较需要另行确定具体契约。
